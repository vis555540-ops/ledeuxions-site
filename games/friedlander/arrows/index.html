Arrows

No wrong moves.

Tap an arrow. If it has a clear run to the edge in the direction it points, it slides out. If something is in the way, nothing happens and it shows you what blocked it.

Clearing an arrow can only ever free others, never trap them, so there is no wrong order and no way to get stuck. Pick a size below and start wherever you like.
