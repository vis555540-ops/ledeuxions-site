# Ellaz games (self-hosted copies)

Original: https://github.com/Sigmafier/ellaz-games (https://ellaz.fun) — MIT License, (c) 2026 Sigmafier. See LICENSE.

Built with the project's own standalone target (`STANDALONE_GAME=<id> vite build --config vite.standalone.config.ts`),
which ships no analytics, no cloud sync and no service worker. Only change: the exit button goes to /games/ instead of ellaz.fun.
Fonts bundled by the original (Heebo, Fredoka) are SIL Open Font License.
