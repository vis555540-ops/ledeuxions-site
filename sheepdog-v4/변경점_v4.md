# 양몰이 v4 — 개 여섯 마리 (2026-09-04)

## 바뀐 것
- 개 그림 6종을 점 단위 픽셀아트로 다시 그림 (개/*.png, 32×32, 줄: 가만·걷기·달리기·하품·앉기·짖기)
  보더콜리 / 코기 / 골든리트리버 / 진도견 / 삽살개 / 저먼셰퍼드
- 첫화면에 개 고르기 칸. 칸 안 그림이 살아 움직인다: 가만 → 4초 쉬면 앉기, 누르면 짖기(그 개 소리).
- 개는 탄을 깨면서 얻는다 (여는탄): 보더콜리 1 · 코기 3 · 골든 5 · 진도견 6 · 삽살개 8 · 셰퍼드 9
  잠긴 개는 검은 그림자 + "n탄에서". 탄을 깨면 끝화면에 "새 개를 얻었다".
- 끝화면에 「개 바꾸기」 단추 → 첫화면으로 돌아가 고른다.
- 개마다 수치: 속도(최고 빠르기 배수), 겁(양이 무서워하는 정도), 짖는 소리(소리/짖기_이름.mp3, 없으면 합성음)
- 고른 개는 저장(기록.개). sw.js 판 v4, 새 파일 캐시 목록에 추가.

## 그림 고치기
`개_그리기.py`의 `종들`에서 색·귀·꼬리·다리 길이·이마줄·안장·털을 바꾸고 다시 실행하면 개/*.png와 미리보기/*.gif가 새로 나온다.
새 개를 넣으려면 `종들`에 한 줄 + index.html `개들`에 한 줄 + sw.js 목록에 파일 한 줄.
