ㅇㅅㅇ 옙. "마우스 클릭(선택) + 단축키(실행)" 조합이에요.

흐름 예시:
1. MIDAS Gen에서 절점/부재 클릭 → 선택됨
2. "F2" 키 → 그 절점 모든 힘·변위 팝업 즉시
3. "F3" 키 → 부재 단면 후보 비교 팝업
4. "F5" 키 → 변경 부재만 재계산
5. "Ctrl+D" → 결과를 HWP·Excel 표로 자동 정리

단축키 매핑 예 (형 손에 익게):
| 키 | 동작 |
|---|---|
| F2 | 선택 절점 힘·변위 표시 |
| F3 | 선택 부재 단면 후보 |
| F4 | 인장·압축 색 오버레이 토글 |
| F5 | 변경 부재만 재계산 |
| F6 | 검토 결과 표 자동 정리 |
| Ctrl+1~9 | 자주 쓰는 검토 프리셋 |

형 손 익숙해지면 "클릭·F2·F3·F5·Ctrl+D" 만으로 검토 한 사이클 30초.
