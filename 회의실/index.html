1단계 — 데이터 단일화 (Single Source of Truth)
건물당 JSON 하나: {건물ID, 39항목: [등급], ...}
형(사람)의 판정은 이 JSON에만 기록. hwpx는 이 JSON에서 파생만 된다. 문서를 직접 수정하지 않는다.
2단계 — 규칙 명문화 (rules.md, 코드가 읽는 스펙)
해당없음 = 분자·분모 완전 제외
등급→점수: 우수10 / 양호8 / 보통6 / 미흡4 / 불량2 / 해당없음 '-'
소계 = Σ(항목점수) 방식, 등급컷 90/75/60/50
이음·맥부장 둘 다 이 파일만 참조. 규칙이 두 곳에 다르게 적혀 있으면 크로스체크가 무의미해진다.
3단계 — 이중 독립 계산 (지금 하던 것, 유지)
이음 엔진 vs 맥부장 엔진, 같은 JSON 입력 → 점수 산출
불일치 건물만 목록으로 뽑음. 일치하면 사람 안 봄.
4단계 — 라운드트립 검증 (이게 지금 빠진 것, 오늘 버그의 해답)
생성된 hwpx를 파서로 다시 읽어서 원본 JSON과 diff하는 스크립트
검사 항목(전부 기계 판정 가능):
각 항목 ▣가 정확히 1개인가
▣ 위치 = JSON 등급인가 (해당없음인데 ▣보통 → 즉시 FAIL)
점수 셀 = 등급→점수 매핑인가
