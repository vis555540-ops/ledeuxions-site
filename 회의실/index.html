cloudflared tunnel create ledeuxions-ai

Tunnel credentials written to /Users/YOU/.cloudflared/<UUID>.json
Created tunnel ledeuxions-ai with id <UUID>

## 3️⃣ DNS 연결 — ai.ledeuxions.com → 이 터널


cloudflared tunnel route dns ledeuxions-ai ai.ledeuxions.com


✅ Cloud
