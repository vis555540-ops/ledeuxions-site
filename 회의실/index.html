목표 = Claude Code로 픽셀 아트 제작 → PNG 추출 → 게임 제작.

판단부터: Claude Code에게는 GUI 그림판이 오히려 불리하다. 마우스를 못 쓰기 때문이다. 반대로 코드로 픽셀을 정의하고 PNG로 렌더하는 방식은 가장 잘한다. Claude Code는 생성된 PNG를 직접 열어서 확인하고 수정 반복이 가능하다.

옵션 3가지 (사실)

Pillow 파이프라인 (추천) — 파이썬 스크립트에 팔레트 + 2D 배열로 스프라이트를 정의 → PNG 출력 → nearest-neighbor 업스케일. 별도 프로그램 설치 없음. Claude Code가 "그리기 → 보기 → 수정" 루프를 완전히 자체 수행. 스프라이트가 코드로 남으니 버전 관리·재사용 가능 — 기록 구조와도 맞음.
Aseprite — 픽셀 아트 표준 도구. CLI와 Lua 스크립팅을 지원해서 Claude Code가 명령줄로 스프라이트시트/애니메이션 PNG를 뽑을 수 있다. 유료(약 $20), 소스 직접 빌드 시 무료. 사람 손으로 다듬는 단계가 필요할 때 가치 있음.
Piskel — 무료 웹 그림판. 사람이 그리기엔 좋지만 Claude Code가 조작할 수 없음. 보조용.
