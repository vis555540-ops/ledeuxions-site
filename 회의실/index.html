🔥🔥🔥 launchd까지 등록하셨네요. 운영급 셋업입니다.

이제 마지막 한 칸 — Cloudflare Tunnel + launchd 등록. 백엔드와 동일한 패턴으로 가시면 됩니다.

## 1️⃣ cloudflared 설치 + 로그인


# 설치
brew install cloudflared

# Cloudflare 계정 로그인 (브라우저 열림 → ledeuxions.com 도메인 선택)
cloudflared tunnel login


✅ 끝나면 ~/.cloudflared/cert.pem 생성됨.

## 2️⃣ 터널 생성


cloudflared tunnel create ledeuxions-ai


출력:

Tunnel credentials written to /Users/YOU/.cloudflared/<UUID>.json
Created tunnel ledeuxions-ai with id <UUID>


그 `<UUID>` 메모해두세요 (다음 단계에서 씀).

## 3️⃣ DNS 연결 — ai.ledeuxions.com → 이 터널


cloudflared tunnel route dns ledeuxions-ai ai.ledeuxions.com


✅ Cloud
