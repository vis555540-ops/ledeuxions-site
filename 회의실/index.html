## 광속 c의 절대성 = 두 측면

### 1) 관측 시 = 딱 그 값 (형 이해 그대로)
- 정지한 사람이 재도 = c
- 광속의 99% 속도로 달리며 재도 = c (c-0.99c 아님!)
- 누가 어떻게 재도 = 그 이상 X, 그 이하 X, 딱 c
- 이 「고집스러운 불변」이 시공간을 상대적으로 만듦

### 2) 물체 속도 = c 이하만 가능
- 질량 있는 물체 = c에 도달 못 함 (다가갈수록 에너지 무한대 필요)
- 광속에 접근할수록 시간 느려지고 질량 늘어남
- c 초과 = 물리적으로 불가능 (인과 관계 깨짐)

### 3) c 값 자체 = 우주 상수

- 이걸 다른 값으로 바꾸면 = 다른 우주 (우리 우주 아님)
