Why PDFs bloat up in the first place

Most oversized PDFs aren't heavy because of text — text is tiny. They're heavy because of images: a scanner set to a high DPI, or photos pasted in at full resolution when the page is only going to be viewed at a fraction of that size. Compressing a PDF mostly means re-encoding those images at a size that still looks sharp on screen, without carrying pixels nobody will ever see.

How it works here

The compressor runs in your browser tab. Drop the file in, pick a compression level, and it re-encodes the PDF locally — nothing is uploaded to a server in the process. When it's done you get the smaller file straight back, ready to attach.

Common questions

Will compressing make the text blurry?No — text stays sharp because it's vector data, not an image. Compression targets the embedded images and how they're re-encoded, so text-heavy pages barely change size but stay crisp.
What if I need an exact file size, like under 10MB?There's a target-size mode that lets you aim for an exact MB or KB figure instead of just picking "low/medium/high" — useful when an email system has a hard cutoff.
Is my file uploaded anywhere while this happens?No, the compression itself runs on your device. Nothing needs to leave your browser tab for the file to get smaller.
