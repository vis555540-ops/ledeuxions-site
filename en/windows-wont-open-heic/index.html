Common questions

Why does my iPhone even use HEIC?It's a newer, smaller file format Apple switched to by default. It saves storage space, but a lot of non-Apple software doesn't support it yet.
Can I make my iPhone save as JPG instead, so this doesn't keep happening?Yes — on iPhone go to Settings → Camera → Formats → Most Compatible. New photos will save as JPG from then on.
Will converting lose quality?No — it's a direct re-encode of the same image data, not a re-compression.
