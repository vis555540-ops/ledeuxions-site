Why does this matter?

A lot of the audio people convert isn't public — a voice note, a meeting recording, a demo track. Sending it to a stranger's server for a few seconds so it can be "converted" is a habit worth breaking when it doesn't have to happen at all. If the conversion runs on your own device, the file simply never leaves it.

How it works

Your browser decodes the audio file directly and re-encodes it to MP3 using code that runs locally, the same way a desktop audio app would. No upload, no waiting on someone else's queue. You can convert several files in one go, and you can pick the output bitrate yourself.

Common questions

Which formats can I convert from?WAV, M4A, OGG, FLAC, and most other common audio formats your browser can already play. If the browser can open it, the converter can usually read it.
Does it work on a phone, or only a computer?Any modern browser works — iPhone, Android, Windows, or Mac. It's especially useful for turning an iPhone voice memo (M4A) into an MP3 that plays everywhere.
Is there a quality loss?Any conversion to MP3 is lossy by nature (that's what MP3 is), but you control the bitrate — a higher bitrate keeps more detail, a lower one makes a smaller file. Nothing gets compressed further than what you choose.
