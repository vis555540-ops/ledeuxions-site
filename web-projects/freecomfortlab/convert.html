파일 변환 실험실

현재는 mp3 변환 테스트만 연결되어 있습니다.
실제 변환 품질·속도 검증을 위한 실험 페이지입니다.

1차 실험: mp3 변환 테스트
아래 폼은 집 노트북 Flask 서버 + Cloudflare Worker와 연결되어 있습니다.
지금은 “서버까지 파일이 잘 도착하는지”를 확인하는 단계입니다.
선택된 파일 없음
· 유튜브에서 받은 음원, 녹음 파일 등 음성/영상 파일을 올려주세요.
· 현재는 텍스트 파일을 올려도 서버까지는 전송되지만, 실제 변환은 mp3용으로 설계 중입니다.
· 실제 변환은 우선 mp3만 연결하고,
· 이후 wav / mp4 / 원본 유지 옵션을 순차적으로 추가할 계획입니다.
아직 요청 전입니다. 파일을 선택하고 [변환 요청 보내기]를 눌러주세요.
현재 구조: Cloudflare Pages → Worker → 집 노트북 Flask 서버(/api/convert)
