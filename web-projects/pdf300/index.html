      자주 묻는 질문

      내 파일이 서버로 올라가나요?

      브라우저 도구 14개는 올라가지 않습니다. 합치기·나누기·자르기·압축·서명·가리기 같은 작업은 전부 여러분 브라우저 안에서 처리되고, 파일은 기기 밖으로 나가지 않습니다. 고급 도구 10개(OCR·암호·복구·오피스 변환)는 브라우저에서 할 수 없는 작업이라 서버가 필요하며, SRV 표시가 붙어 있습니다.

      정말 무료인가요?

      네. 지금은 24개 도구를 모두 무료로 쓸 수 있고, 브라우저 도구 14개는 앞으로도 계속 무제한 무료입니다.

      가입해야 하나요?

      아니요. 회원가입도, 로그인도, 이메일도 필요 없습니다.

      결과물에 워터마크가 찍히나요?

      아니요. 저희가 만든 결과물에는 워터마크도 로고도 넣지 않습니다.

      파일 크기 제한이 있나요?

      브라우저 도구는 기기 메모리가 감당하는 만큼 처리됩니다. 서버 도구는 파일이 오가야 해서 현실적인 제한이 있습니다.

      어떤 도구가 서버를 쓰나요?

      고화질 압축, OCR, 암호 걸기, 암호 풀기, 메타데이터 제거, 복구, 쪽번호, 모아찍기, 워터마크, 오피스→PDF 변환입니다.

      인터넷이 끊겨도 되나요?

      페이지가 한 번 열린 뒤에는 브라우저 도구가 오프라인에서도 동작합니다. 서버 도구는 연결이 필요합니다.
