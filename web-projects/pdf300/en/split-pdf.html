Split a PDF by page range

Keep the pages you need and leave the rest. Say which pages, and get them back as their own file.

Open the tool

How it works

  1. Add the PDFDrop the file onto the page. It stays on your device.
  2. Say which pagesA range like 3-7, or single pages. Page numbers are the ones printed in the reader.
  3. DownloadSave the new file with only those pages.

Questions

Does splitting change the original file?

No. A new file is built and downloaded; the file on your device is left as it was.

Can I pull one page out?

Yes — name a single page instead of a range.

Guide: doing it well

When to split a PDF

Splitting is the other half of merging. Someone sends you a 60-page bundle and you only need the contract pages. A portal wants the passport scan and the bank statement uploaded in separate slots, but they arrived in one file. A scan is too big to upload, and cutting it into two parts gets each part under the limit. Or you simply want to send one page without sending the rest.

The three split modes

By page range. Type ranges separated by commas, such as 1-3, 5, 7-10. Each range becomes its own file, so that example gives you three PDFs: pages 1–3, page 5, and pages 7–10.

Every single page. One file per page. Useful for scanned forms where each page is a separate document.

Every N pages. Fixed-size groups. A 20-page file split every 5 pages gives four files. This is the quickest way to cut an oversized file into uploadable parts.

The results come back together in one ZIP file, named after the original with the page numbers added.

Step by step

  1. Open the Split tool and choose one PDF.The page count appears once it loads.
  2. Pick a mode and type the range.Page numbers are the physical page positions (1 is the first page of the file), not the numbers printed on the pages.
  3. Download the ZIP and extract it.On most computers double-clicking the ZIP opens it.

Tips

Printed page numbers and file page numbers often differ. A report with a cover and a contents page might print "1" on the third page of the file. Look at the page counter in your PDF reader, not at the footer. If you only want to drop a few pages rather than extract some, Rotate & reorder lets you remove pages visually and save one file.

Splitting copies pages without re-encoding, so each part has the same quality as the original. If a single page is still large, it is because of what is on that page — usually a high-resolution scan — and compression is the fix.

Privacy

Split runs in your browser. The PDF is not uploaded; the ZIP is built in this tab with JSZip and saved directly to your device.

Common problems

"No valid page range." Check for page numbers higher than the page count, or for letters and spaces in odd places. 2-4,6 and 2-4, 6 both work.

The file will not open. Password-protected files have to be unlocked first. Damaged files can sometimes be recovered with Repair PDF.

More questions

Can I get the selected pages as one file instead of several?

Yes: type them as one range if they are consecutive, or remove the unwanted pages with Rotate & reorder and save.

Does splitting change the original?

No. New files are created; the original on your device is untouched.

Is quality reduced?

No. Pages are copied as they are.

Is there a page limit?

No fixed limit. Very large scans depend on your device's memory.

Do I need an account?

No account, no watermark, no daily limit for browser tools.
