종이에 찍은 도장·서명을
전자문서용 투명 PNG로 바꿉니다.

A4 흰 종이에 도장을 찍거나, 검정색 볼펜으로 서명을 한 뒤 사진을 업로드하면
배경을 제거하고 검정색 선의 투명 PNG로 정리해 줍니다. PDF 전자서명, 계약서 이미지 서명에 바로 사용할 수 있습니다.

브라우저에서 파일을 업로드하지만, 결과 이미지를 제외한 원본은 별도 보관하지 않습니다.

1. 도장 / 서명 이미지 업로드

흰 배경 위에 찍힌 도장 또는 검정색 서명 이미지를 업로드해 주세요. 해상도가 높을수록 결과가 깔끔합니다.

JPG, PNG 등 대부분의 이미지 형식을 지원합니다. 그림자가 적고 배경이 밝을수록 좋습니다.

서명이 너무 가늘게 보이면 값을 높이고, 너무 두껍게 보이면 값을 낮춰 보세요. (현재 서버가 대비 값을 무시하는 경우 기본값으로 동작합니다.)

이미지를 선택한 뒤 버튼을 눌러 주세요.
※ 결과는 모노크롬(검정색 선) 위주의 PNG를 목표로 합니다. 원본에 색상이 섞여 있으면 일부 색이 남을 수 있습니다.
※ 중요한 인감/서명은 항상 출력 후 육안으로 검토하고, 테스트 문서로 먼저 사용해 보시길 권장합니다.

2. 결과 확인 · PNG 다운로드

왼쪽에는 원본 이미지, 오른쪽에는 배경 제거 결과가 표시됩니다. 결과 이미지는 투명 PNG로 저장할 수 있습니다.

원본 이미지
배경 제거 결과 (PNG)
결과가 생성되면 다운로드 버튼이 활성화됩니다.
서버 엔드포인트: http://localhost:8100/extract
로컬에서 실행 중인 stamp-ai-server가 이 요청을 처리합니다.

권장 사용 방법

1 흰 종이에 도장/서명 준비

빛 반사가 적은 곳에서 A4 흰 종이에 도장을 찍거나, 검정색 펜으로 서명을 크게 써 주세요.

2 사진 촬영 및 업로드

스마트폰으로 정면에서 촬영한 뒤, 이 페이지에 이미지를 업로드합니다. 그림자·기울어짐이 적을수록 정확도가 높습니다.

3 결과 확인 후 전자문서에 삽입

다운로드한 PNG를 PDF 편집기나 워드, 전자계약 서비스의 서명/도장 삽입 기능에서 사용하면 됩니다.
