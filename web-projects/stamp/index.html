도장 만들기

이름만으로 1초 만에 만들거나, 찍힌 도장 사진에서 배경을 깨끗하게 제거합니다.

도장 설정

「자연스럽게」는 실제 찍은 도장처럼 잉크 번짐과 거친 질감을 넣고, 「깔끔하게」는 선명한 디지털 도장을 만듭니다.

한자 2~4글자 또는 한글 2~3글자가 가장 자연스럽습니다.

📷
도장 사진을 끌어 놓거나 클릭해 선택
흰 종이에 찍힌 도장이 가장 잘 추출됩니다.

배경 제거 설정

높일수록 배경이 더 많이 제거됩니다. 도장이 흐려지면 낮춰주세요.

원본 색을 유지하려면 첫 번째(체크무늬)를 선택하세요.

도장을 찍을 문서가 PDF인가요? pdf300.com — 합치기·나누기·용량 줄이기, 설치 없이.

쓰다가 아쉬운 점 있으면 메일로 알려주세요.
